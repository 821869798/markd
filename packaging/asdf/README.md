# asdf-mkd

[asdf](https://asdf-vm.com) / [mise](https://mise.jdx.dev) plugin for
[mkd](https://github.com/821869798/markd) — the cross-platform directory
bookmark manager.

## Install

With mise (recommended):

```console
mise use -g mkd@latest
```

With asdf:

```console
asdf plugin add mkd https://github.com/821869798/asdf-mkd.git
asdf install mkd latest
asdf global mkd latest
```

After installing, run `mkd setup` to register the shell function.
